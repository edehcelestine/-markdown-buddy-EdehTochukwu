# Project Reflection & AI Workflows

### 1. What are the core strengths and weaknesses of using generative AI for documentation tasks?
* **Strengths:** AI dramatically accelerates the initial boilerplate drafting process. It provides clean structural scaffolding that guarantees important fields like installation parameters, licensing, and clean syntax formatting are not left out.
* **Weaknesses:** Generative models lack absolute context about specific project execution variations. If left unedited, AI-generated documentation can sometimes present overly generalized instructions, include dead asset paths, or make incorrect assumptions about specific software library dependency versions.

### 2. How did iterative prompting affect the quality and clarity of your output?
Moving through sequential phases—starting from a generic structure request, progressing to text refinement, and finishing with a syntax-correcting critique prompt—helped strip away generic text fluff. The iterative method isolated exactly what technical information belonged in a professional data project repository and kept the documentation clean and concise.

### 3. Detail the ethical boundaries and verification checks you performed during this assignment.
In line with academic integrity standards, this AI model acted strictly as a design and formatting assistant. No algorithmic calculations or synthetic numeric distributions were generated or calculated via AI. Document outputs were manually reviewed against the structural documentation patterns found in industry-standard libraries (like tidyverse core packages). Markdown text syntax was verified for visual mapping accuracy through live file preview rendering.
